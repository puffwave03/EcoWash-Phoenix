# Phoenix Brand Assets

Current approved Phoenix branding for the public product experience.

## Full logo masters

- `Phoenix_by_EcoWash_APPROVED.png` — exact approved raster master used by the public site and social metadata.
- `Phoenix_by_EcoWash_APPROVED.webp` — optimized approved raster export.
- `Phoenix_by_EcoWash_APPROVED.svg` — approved archival/vector-container export.

## Product mark

- `phoenix-product-mark.svg` — compact Phoenix blue/cyan/green symbol derived from the approved logo, without wordmark. This is the current technical product mark for browser/site icons.

## Usage rule

- Public informational site: Phoenix by EcoWash branding.
- Browser/site iconography: `phoenix-product-mark.svg`.
- Tenant/laundry branding: configured inside the tenant application; do not use tenant logos as the global Phoenix public brand.

Legacy `ecowash-product-mark.svg` and the old EcoWash public/social icon set are retired and must not be reintroduced as current branding.
